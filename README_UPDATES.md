## 📞 Support

### If Something Isn't Working

**WhatsApp button not showing?**
- Clear browser cache (Ctrl+Shift+Delete)
- Restart dev server
- Check browser console for errors (F12)

**Enquiry form not opening?**
- Scroll to footer completely
- Click the gold "Enquire Now" button
- Check browser console for errors

**Logo not displaying?**
- Ensure file exists at: `/frontend/public/images/logo/thanekar-logo.png`
- File should be PNG with transparent background
- Recommended size: 100x100px

**Floor plans misaligned?**
- Clear browser cache
- Test on different screen sizes
- Check that CSS is loaded (open Developer Tools)
